라이브 캡션 자막을 가져옵니다

Windows 11의 라이브 캡션이 만든 자막을 SignalScript Engine이 읽어 이 화면에 복사 가능한 텍스트로 보여줍니다.

  1. Start-Engine.cmd를 실행합니다. 라이브 캡션이 자동으로 켜집니다.
  2. 라이브 캡션 설정(⚙)에서 언어를 한국어, 마이크 오디오 포함을 켭니다.
  3. 이 화면에서 전사 시작을 누릅니다.

로컬 엔진 연결을 확인하고 있습니다…

Windows용 로컬 엔진 다운로드

WINDOWS LOCAL ENGINE

로컬 엔진 설치 방법

  1. Node.js LTS 설치 페이지를 열어 LTS 버전을 설치합니다.
  2. Windows용 로컬 엔진 다운로드를 눌러 압축을 푼 뒤 폴더를 엽니다.
  3. Start-Engine.cmd를 두 번 클릭합니다. 열린 창은 전사 중에 닫지 마세요.
  4. 이 사이트를 새로고침해 “로컬 엔진 연결됨”을 확인합니다.

Windows 11 라이브 캡션(한국어 지원)이 필요합니다. 별도 모델 다운로드는 없고, 전사문은 외부로 전송되지 않습니다.

전사 내용

시작하면 라이브 캡션의 자막을 가져옵니다.

전사문은 서버로 전송하거나 저장하지 않습니다.
