# SignalScript Engine

SignalScript 웹앱을 위한 Windows 로컬 엔진입니다. Windows 11의 **라이브 캡션**(`Win+Ctrl+L`)이 만든 자막 글자를 읽어 웹앱으로 전달합니다. `127.0.0.1`에서만 실행되며 별도 모델이나 인터넷 연결이 필요 없습니다.

## 사용 방법

1. `Start-Engine.cmd`를 실행합니다. 라이브 캡션이 꺼져 있으면 자동으로 켭니다. 열린 창은 전사하는 동안 그대로 둡니다.
2. 라이브 캡션 창의 설정(⚙) → **마이크 오디오 포함**을 켜면 내 목소리도 함께 전사됩니다. 언어는 **한국어**로 설정합니다.
3. SignalScript 웹사이트를 열어 “로컬 엔진 연결됨”을 확인하고 **전사 시작**을 누릅니다.

## 요구 사항

- Windows 11 (라이브 캡션 한국어 지원 버전)
- Node.js 20 이상 ([Node.js LTS](https://nodejs.org))

## 보안

엔진은 `127.0.0.1`에서만 요청을 받고 Vercel과 localhost 웹페이지에서 온 요청만 허용합니다. 전사문은 저장하거나 외부로 전송하지 않습니다.
