# SignalScript

시스템 오디오와 마이크를 함께 받아 브라우저 안에서 Whisper로 전사하는 무료 정적 웹앱입니다. 음성 및 전사문은 서버나 외부 API로 전송하지 않습니다. 첫 실행 시 모델 파일만 내려받고 브라우저 캐시에 보관합니다.

## 사용 방법

1. Chrome 또는 Edge에서 사이트를 엽니다.
2. **연결하고 시작**을 누릅니다.
3. 공유 창에서 **전체 화면**과 **시스템 오디오 공유**를 선택합니다.
4. 마이크 권한을 허용합니다.
5. 전사문을 편집, 복사하거나 TXT로 저장합니다.

## 배포

정적 파일만 사용하는 앱입니다. GitHub에 올린 뒤 Vercel에서 해당 저장소를 Import하면 빌드 설정 없이 배포할 수 있습니다.

## 로컬 실행

브라우저 보안 정책 때문에 `index.html` 파일을 직접 열지 말고, 프로젝트 폴더에서 정적 웹 서버로 여세요.

```powershell
npx serve .
```

표시된 주소(보통 `http://localhost:3000`)를 최신 Chrome 또는 Edge로 엽니다. `npx`를 사용하고 싶지 않다면 VS Code의 Live Server 확장으로 같은 폴더를 열어도 됩니다.

## 제한 사항

- 브라우저 보안 정책상 매번 시스템 오디오 공유를 사용자가 직접 허용해야 합니다.
- 첫 실행에는 Whisper 모델 다운로드가 필요합니다. 이후 모델은 브라우저 캐시에 저장됩니다.
- 시스템 오디오 공유는 Chrome/Edge 및 Windows에서 가장 안정적입니다.
